## 仍未满足、因此不能发布模块的条件

1. 三份 `.ko` 的完整对应源码：kpatch / create-diff-object / create-klp-module 的输入、脚本、工具链和内核构建树。
2. CVE-2026-99999 重建 diff 与模块字节的对应关系。
3. 累积 as-built diff 到 `a4efcea8…` 的重编证明。
4. 去掉或合法保留调试信息里的构建机绝对路径，同时仍然满足第 1 条。改路径会改变 SHA-256。
5. 一份由版权人作出、覆盖这些本地内核改动的明确 GPL 授予。现在只有补丁头里的 `sandbox <sandbox@local>`，以及内核上游代码本身的 GPL-2.0。本仓库没有把 `MODULE_LICENSE` 升级成这种授予。

PHP 侧没有把“已有厂商二进制”放进仓库。若以后发布编译结果，还需要目标系统上的构建记录、扩展清单，以及 PHP License 对二进制声明的保留。当前指南在 EL8 构建证据之前停止。
